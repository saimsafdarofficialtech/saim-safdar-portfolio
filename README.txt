SAIM SAFDAR PORTFOLIO — GITHUB PAGES SETUP

1. Keep index.html and profile.jpg together in the same folder.
2. Replace the placeholder email and phone number in index.html with your real contact details.
3. Open your GitHub repository and upload index.html and profile.jpg.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select the main branch and / (root), then Save.
6. After GitHub Pages finishes publishing, open the website URL shown in Settings > Pages.

PHOTO: The HTML expects the image file to be named exactly profile.jpg.
